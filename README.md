# Orbital

**A native IDE for designers and developers — built on VSCodium.**

Orbital bundles a curated set of extensions directly into the editor: always on, always fast, no marketplace management required. Every feature is included out of the box.

> macOS only for now. Windows and Linux are on the roadmap.

---

## Features

### Git AI
Generates commit messages from the staged diff. Supports Claude, GPT-4, Gemini, OpenRouter, and local Ollama models. Also manages multiple Git identities (SSH, HTTPS, GitHub OAuth) per repository.

### Kanban Board
A task board embedded in the workspace — Backlog, To Do, Doing, Done. Cards can be sent directly to any AI agent installed in the IDE.

### KPI Dashboard
Productivity stats at a glance: active hours, files saved, terminal commands, daily streaks, language breakdown, and AI agent usage. Plus a live view of API quota usage for Anthropic, OpenAI, and OpenRouter.

### Moodboard
Image reference collections pinned inside the IDE. Supports AI-generated descriptions and style guides from selected images.

### Slate
Note-taking with backlinks, tags, and an interactive graph view. Think Obsidian — inside the editor. Includes AI ingestion to turn raw documents into structured wiki notes.

### Ollama Agent
A local AI coding agent powered by Ollama, with MCP support (preconfigured for Figma Dev Mode) and filesystem tools for reading and writing workspace files.

### Live Preview
An embedded browser with a local server and auto-refresh for HTML/CSS/JS prototypes. Multiple instances can run simultaneously.

### Mobile Bridge
Connects Orbital to the **OrbitalMonitor** iOS app over local network (no cloud). Sends prompts to any installed AI agent and streams task status back to your phone.

### Agent Workspace
Opens multiple AI agents side by side in a configurable multi-panel layout — Claude Code, Codex, Gemini, Ollama, Cline, and more.

### Terminal Shortcuts
A sidebar dashboard for running and monitoring custom shell commands in the background, with live logs and status per shortcut.

### Project Setup Wizard
Scaffolds the initial structure of Web, iOS, or Android projects, with embedded Markdown instruction files ready for AI agents.
